Design prototype for Task 46. The panel is a dictionary editor over settings.json: each row's control is generated from its descriptor's type (bool→checkbox, enum→select, int/number→number input, text→input). A setting that is not a labelled input opts out with type:"custom" and a named renderer dispatched through the CUSTOM table — Storage › Project caches is the worked example. General › Show developer settings is itself a setting, and reveals the Developer group. Settings data is the Task 45 inventory; values are in-memory only.
