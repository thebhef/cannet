RBS signals

Every field the project's RBS configs transmit. A .cannet_rbs is a sparse override document (ADR 0028): the file records only what you changed, while every transmitted frame is fully populated by the precedence fill_bit → GenSigStartValue → override. The chip says whether a field is yours or not: Default covers both the DBC's start value and the file's fill, since neither is something you set — Detail names which supplied the bits. Messages are rest-of-bus: everything in the database plays unless muted. Signals are not combined across configs: the same signal in two files is two rows, because two sims are meant to differ. An override the encoder cannot apply is dropped — the frame goes out carrying the default while the file still says otherwise, which is the substitution the error rows exist to surface.
