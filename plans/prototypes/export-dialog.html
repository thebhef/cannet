Tokens — usable in the name template and the folder

TokenResolves toStatus
{project} slugified project name (lowercase, runs of non-alphanumerics → “-”) ruled 2026-09-05
{logger} slugified logger name; an error outside a logger ruled 2026-09-06
{start} / {start:%…} capture wall-clock start; falls back to export time when unanchored (preview says so) ruled 2026-09-05
{now} / {now:%…} time of export; for a logger, the time logging started ruled 2026-09-05
relative folder resolved against the project directory (project-directory mode only) ruled 2026-09-06
bare {start} / {now} ISO 8601 basic format with timezone offset, e.g. 20260905T091502-0600 — extended ISO’s colons can’t appear in a Windows file name ruled 2026-09-06
%Y %m %d %H %M %S %z %Z strftime subset for an explicit format inside a token, e.g. {start:%Y%m%d-%H%M%S%z}; %z = -0600 offset, %Z = abbreviation (CST) proposed
